# Mall Customers Data Cleaning - Task 1

## Project Overview

This repository contains the dataset and Python notebook for Task 1 of the Elevate Labs Data Analyst Internship. The objective of this task was to clean and preprocess the Mall Customers dataset to prepare it for further analysis.

## Data Cleaning Summary

- Removed duplicate rows to ensure each customer record is unique.
- Standardized column headers by converting them to lowercase and replacing spaces with underscores.
- Cleaned categorical text values such as the ‘gender’ column for consistent formatting (e.g., 'Male', 'Female').
- Handled missing values by removing rows containing nulls.
- Corrected data types to proper formats, converting age, annual income, and spending score to integer types.
